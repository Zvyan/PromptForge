快速上手 (Codex & 终端)

在 Codex 命令行或本地终端直接使用 CLI 生成与导出

1. 列出所有模板分类 
promptforge list
2. 交互式生成并选择平台 
promptforge generate -c coding -t code_review -p codex -i
3. 导出为 .zcoderules 规则文件 
promptforge export -c coding -t bug_fix -p zcode -o .zcoderules
4. 启动本地可视化 Web UI 
promptforge web --port 8000
